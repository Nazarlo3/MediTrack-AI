# ЛР6 — тривалість та інтенсивність

Цей набір створено 20.10.2026 **до реалізації** нового розширення: [план і пороги](../../../docs/impl/feature_16/plan.md).

- Baseline: 0.3 із 16 категоріями/контекстом, без structured details; знімок промпту й SHA-256 ai_service.py до редагування.
- Current: та сама модель, temperature 0.1, max_tokens=400 і timeout; додано поля, підготовку даних та правила їх використання. Source commit — початковий HEAD; робочі зміни визначаються source_file_sha256/prompt_sha256, не вигаданим фінальним комітом.
- 5 спільних регресій повторено дослівно з набору 18.10, ще 5 — нові сценарії. Це не відновлені історичні вводи ЛР4. Приклад ушкодження однозначний: удар гомілкою об ліжко.
- Умови current: 5/5 регресій, 5/5 нових категорій/чисел у поясненні/details_used, 10/10 валідних відповідей. Передача прапорця сама по собі не зараховує змістовне використання. Збереження точних чисел — інженерна відповідність; медична точність і клінічна адекватність не вимірюються.

```powershell
python backend/evaluation/run.py --suite details
python backend/evaluation/run.py --suite details --live
```

Без --live мережі немає. Живий запуск — 20 синтетичних запитів, типово пауза 15 с; runtime-провайдер залишається без автоматичних повторів. Старі 18.10 результати й промпти не перезаписуються: `--suite legacy` запускає тільки їхні зафіксовані конфігурації, це не нова функція. Усі спроби/затримки/модель/параметри/пакети — в окремих results JSON. Ключі/заголовки/.env не пишуться.

Мобільний opt-in сценарій: `Lab5PhoneScenarioTest#lab6DurationAndIntensityReachAIAndHistory` із тими самими `lab5Phone=true`, `lab5BaseUrl=http://127.0.0.1:18765/`, тестовим reverse та ізольованими prefs. Потрібні оновлені debug і test APK; встановлювати через install -r без видалення даних. Перевіряються відмова для 31 дня, введення 3/5, зміст живої відповіді, уточнення й деталі збереженої історії. Це два додаткові Groq-виклики.
