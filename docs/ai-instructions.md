# AI Agent Instructions — MediTrack AI

Цей документ задає суворі правила та порядок роботи AI Coding Agent з репозиторієм MediTrack AI.

## Порядок роботи над кожною задачею
1. **Аналіз:** Перед унесенням змін прочитати документацію в папці `docs/` та перевірити фактичну структуру репозиторію.
2. **Планування:** Спочатку пояснити поточну реалізацію та запропонувати мінімальний чіткий план дій.
3. **Список файлів:** Чітко перерахувати файли, які потрібно створити або змінити.
4. **Покрокова реалізація:** Виконувати роботу короткими ітераціями, реалізуючи один завершений крок за раз.
5. **Перевірка:** Для змін поведінки додати або оновити змістовні тести валідації та регресійні перевірки попереднього сценарію. Виконати відповідні перевірки й переглянути diff перед комітом.
6. **Підсумок:** Після реалізації підсумувати внесені зміни, команди перевірки та відомі ризики. Відокремлювати виконані перевірки від запланованих і повідомлених користувачем; не вигадувати логи, промпти чи результати.

## Обмеження та заборони
- **Заборона повного рефакторингу:** Не переписувати весь проєкт заради виконання локальної задачі.
- **Стабільність API:** Не змінювати існуючий API-контракт без обґрунтування та обов'язкового оновлення документації в `docs/api-contract.md`.
- **Залежності:** Не додавати нові сторонні бібліотеки/залежності без чіткого обґрунтування.
- **Безпека секретів:** Категорично заборонено зберігати API-ключі чи секрети в коді, промптах або Git. Використовувати лише `.env` та змінні середовища.
- **Збереження сумісності:** Перевіряти, що попередній сценарій (категоризація симптомів) продовжує працювати без регресії; зазначати межі перевірки.
