# Testing Guide — MediTrack AI

## Команди запуску

### Mобільний додаток (Android Studio)
- Збірка проєкту: `./gradlew assembleDebug`
- Запуск на пристрої: Натиснути **Run 'app'** (`Shift` + `F10`) в Android Studio.

### Сервер (FastAPI локально)
```bash
cd backend
pip install -r requirements.txt
python main.py
```

---

## Обов'язкові тестові сценарії

1. **Коректні дані:** Ввести *"болить голова і нудить"* ➔ Отримати картку з категорією `загальне нездужання` та поясненням.
2. **Порожні дані:** Ввести порожній рядок або пробіли ➔ Отримати локальну помилку валідації у UI без надсилання запиту.
3. **Холодний старт сервера:** Зачекати прокидання сервера Render (~20 сек) ➔ Додаток відображає індикатор та інформаційне повідомлення, після чого успішно виводить результат.
4. **Вимкнений інтернет / Помилка мережі:** Вимкнути інтернет на пристрої ➔ Додаток виводить картку помилки з кнопкою *"Спробувати ще раз"*.
5. **Повторна спроба:** Змінити текст симптому і натиснути *"Перевірити"* повторно ➔ Отримати оновлений результат без перезапуску застосунку.
