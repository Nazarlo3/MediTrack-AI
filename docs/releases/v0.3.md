# MediTrack AI 0.3

## Нові можливості

- Редагування препарату зі збереженням ID, фото й позначок незмінених часів.
- До 12 часів прийому на препарат; окремий статус за сьогодні та нагадування для кожного часу.
- Кнопки сповіщення «Прийняв» і «Через 10 хв»; відкладення лише в межах тієї самої локальної дати.
- Зелене підсвічення прийнятого часу; вся картка підсвічується після всіх прийомів за сьогодні.
- Налаштування теми: системна, світла, темна; вибір зберігається.
- Уточнення симптомів із контекстом: до трьох у межах перевірки, питання від AI й окремі історичні результати.
- «Скасувати аналіз» без втрати початкового вводу або чернетки уточнення; скасований запит не поповнює історію.

Порівняно з APK 0.2 також доступні 16 категорій симптомів, деталі історії та видалення одного запису з підтвердженням. Частину цих змін уже було закомічено раніше, але їх не було у старому release APK.

## Внутрішні зміни

- Android: незалежні domain-моделі, repository/use case, mapper, ручна DI та типізовані помилки для аналізу й історії.
- FastAPI: AnalysisService, AIProvider з GroqProvider/FakeProvider, централізована конфігурація й domain errors.
- Серверний request_id у X-Request-ID та логах без зміни шести полів успішної JSON-відповіді.
- Перенесення ліків до локального формату v3 із читанням попередніх записів.
- Оновлені README, Knowledge Base, плани й журнали; додані незалежні та сценарні тести.

## APK та оновлення

Версія 0.3, versionCode 3, Android 10+ (API 29). Підготовлений release APK займає приблизно 2,72 МБ (2 724 349 байтів): він оптимізований R8 і підписаний тим самим release-ключем, що APK 0.2. Підпис, версію й вимкнений debug-режим перевірено SDK-інструментами. SHA256SUMS.txt готується поруч із APK.

- Release 0.2 → 0.3: за однакового release-підпису оновлювати поверх, без видалення застосунку.
- Debug → release: підписи різні, встановлення поверх неможливе. Видалення стирає дані; спочатку збережіть потрібну інформацію. На Xiaomi пакет може також залишатися в «Другому просторі» або іншому профілі.
- Старий APK 0.2 не читає нові зміни ліків v3: відкат коду не є відкатом даних.

## Backend та межі

Для AI-уточнень потрібен backend із цієї версії та серверний GROQ_API_KEY поза кодом. Ключ у телефон вводити не потрібно. Якщо сервер не підтримує context, клієнт повідомляє про це; встановлення APK саме по собі не оновлює Render.

16-категорійну класифікацію, контекст і запити перевіряли локально; стан актуального Render після цих змін не підтверджений. Локальний fake — тільки явно синтетична демонстрація, не медичний fallback. AI не ставить діагноз і не призначає лікування.

Доставка нагадувань залежить від дозволів та обмежень Android/Xiaomi. Контекст не відновлюється після завершення процесу; власного шифрування SharedPreferences немає. Команди й докази перевірок: [testing.md](../testing.md).
