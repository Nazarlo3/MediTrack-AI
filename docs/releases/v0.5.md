# MediTrack AI 0.5 — Google Sheets

Статус: підготовка оновлення, GitHub Release ще не публікувався.

- Добровільний збір нових запитів і відповідей у приватній Google-таблиці та актуальна статистика.
- Явне повідомлення про Google, згода версії 2, перемикач і видалення записів цього встановлення.
- Окремий стан браку даних з уточненням, сумісність старої історії/відповідей.
- Збережено ліки, нагадування й локальну історію. Зібрані дані не навчають модель автоматично.

Android 0.5/code 5; підготовлений debug працює через HTTPS Render. Для роботи збору потрібні оновлений backend/серверні секрети; сама наявність APK не підтверджує розгортання. Google-історія версій може зберігати старі дані після видалення поточних рядків.
