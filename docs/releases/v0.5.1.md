# MediTrack AI 0.5.1

Android 0.5.1 / versionCode 6. Оновлення налаштувань, надійності й захисту API.

- Виправлено застарілий стан перемикача збору даних після перестворення Activity.
- Налаштування винесено на окремий екран: GitHub, встановлена версія/тип збірки, Android/пристрій, дозволи та найближче нагадування, лічильники локальних даних. Додано перевірку backend і копіювання технічної діагностики без симптомів, відповідей та ключів.
- API отримав обмеження частоти, одночасності й розміру запитів. Усунено наповнення реєстру відкликань невідомими DELETE; у release заборонено незашифрований HTTP.
- Нагадування позначається доставленим після успішної публікації; при збої — до трьох повторів у межах дня.
- За налаштованого постійного диска Google-черга фіксує задачу в SQLite до статусу queued, відновлюється після запуску, повторює збої та не дублює записи. Видалення відкликає також відкладені задачі. Сирі ключі в outbox не записуються; тексти зберігаються максимум 24 години роботи сервера до очищення, успішні задачі прибираються одразу.

Без `COLLECTION_OUTBOX_PATH` Google-запис синхронний: saved означає підтверджений Google-запис, unavailable — збереження не підтверджене. У безкоштовного Render перевірено відсутність постійного диска; називати локальний SQLite там стійким не можна. Нові платні ресурси не створювалися. Деталі налаштування — [збір даних](../data-collection.md).

Модель не навчається автоматично; застосунок не ставить діагноз. Ліміти API не замінюють автентифікацію; один worker/інстанс обов'язковий. Зібрані дані не є анонімними. Цей документ описує код 0.5.1, публікація нового APK й розгортання відстежуються окремо в [журналі](../impl/release_0_5_1/changelog.md).
