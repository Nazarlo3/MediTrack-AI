## [v0.1.0-alpha] - Лабораторна робота №2 (MVP & Cloud Deployment)
### Додано:
- Початкова реалізація мобільного застосунку на Android (Kotlin, Jetpack Compose, ViewModel, Retrofit).
- Серверна частина на Python / FastAPI з валідацією Pydantic та ендпоінтами `/health` і `/analyze-symptom`.
- Інтеграція з безкоштовним Groq AI API (модель Qwen 27B).
- Безкоштовний деплой бекенду у хмару Render.com (`https://meditrack-ai-xbk5.onrender.com/`).
- Таймаут очікування 60 секунд для обробки холодного старту сервера.
