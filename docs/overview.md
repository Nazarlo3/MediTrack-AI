# Опис проєкту — MediTrack AI

## Загальна концепція
**MediTrack AI** — це мобільний асистент первинної оцінки та категоризації неідентифікаційного опису симптомів користувача на основі штучного інтелекту.

## Основний сценарій використання
1. Користувач вводить текстовий опис свого самопочуття (наприклад: *"болить голова і нудить"*).
2. Мобільний додаток на Kotlin / Jetpack Compose відправляє асинхронний REST API запит на бекенд.
3. Сервер на FastAPI (Render або локальний запуск ЛР7) валідує вхідні дані за допомогою Pydantic та звертається до Groq AI API (модель `qwen/qwen3.8-27b`).
4. Штучний інтелект класифікує опис за однією з 16 категорій, визначає рівень терміновості та формує коротке пояснення.
5. За браку даних застосунок показує питання без запису в історію; придатний результат відображає у кольоровій картці та зберігає до 20 записів між запусками.

## Межі MVP
- Інформаційний характер: додаток НЕ ставить медичні діагнози і НЕ дає рецептів.
- Обмежений фіксований перелік категорій для стабільності демонстрації.
- Backend налаштований на хмарний Render.com; можливі холодний старт і недоступність зовнішніх сервісів.

ЛР6 додала тривалість 1–30 днів та інтенсивність 0–10; ЛР7 — явний NoResult і локальний debug запуск. Актуальна карта — [architecture.md](architecture.md), перевірки — [feature_22](impl/feature_22/verification.md).
