# Опис проєкту — MediTrack AI

## Загальна концепція
**MediTrack AI** — це мобільний асистент первинної оцінки та категоризації неідентифікаційного опису симптомів користувача на основі штучного інтелекту.

## Основний сценарій використання
1. Користувач вводить текстовий опис свого самопочуття (наприклад: *"болить голова і нудить"*).
2. Мобільний додаток на Kotlin / Jetpack Compose відправляє асинхронний REST API запит на бекенд.
3. Сервер на FastAPI (розгорнутий у хмарі Render.com) валідує вхідні дані за допомогою Pydantic та звертається до Groq AI API (модель `qwen/qwen3.8-27b`).
4. Штучний інтелект класифікує опис за однією з 7 категорій, визначає рівень терміновості та формує коротке пояснення.
5. Мобільний додаток відображає результат у вигляді кольорової картки та зберігає до 20 записів локальної історії між запусками.

## Межі MVP
- Інформаційний характер: додаток НЕ ставить медичні діагнози і НЕ дає рецептів.
- Обмежений фіксований перелік категорій для стабільності демонстрації.
- Backend налаштований на хмарний Render.com; можливі холодний старт і недоступність зовнішніх сервісів.
