# ЛР6 — фінальний Git-коміт

Користувач прямо дозволив локальний commit, перевірки та додавання точного хешу до Word-звіту. Push, реліз APK і Render заборонені без окремого дозволу.

1. Переглянути всі зміни, зберегти контрольні SHA-256 робочих файлів і виконати перевірку секретів без друку значень. Виключити `.idea`, `.artifacts`, `docs/various files`, credentials, signing, тимчасові файли та доповнення ЛР1–5.
2. Відібрати Android/backend реалізацію duration_days/intensity/details_used, її JVM/Python/opt-in телефонні тести, evaluator і синтетичні результати ЛР6, README/KB та feature_15/16/21. Для спільних `Lab5PhoneScenarioTest.kt` і `docs/testing.md` підготувати версію лише з частинами ЛР6, не змінюючи сторонніх частин робочих файлів.
3. Відтворити точний кандидат коміту в ізольованій локальній копії HEAD + відібрані файли. Запустити backend-тести без зовнішнього AI та Android unit/lint/debug/test-APK compile; наявні живі протоколи перевірити без повторення Groq чи встановлення APK.
4. Перевірити вміст Git index, whitespace, секрети, відповідність файлів перевіреному кандидату; створити змістовний локальний commit. Жодних git add . / reset / restore / stash, видалення чужих змін або переписування історії.
5. У локальному `docs/various files/Звіти/Звіт_ЛР6_MediTrackAI_v2.docx` додати повний хеш коміту. Зберегти погоджені користувачем текст, результати та обмеження; не повертати вилучені тимчасові статуси публікації. Times New Roman 14, один висновок наприкінці; render та огляд усіх сторінок. Про локальний статус коміту повідомити в чаті.
6. Перевірити, що сторонні файли й невідібрані частини спільних файлів збережені. Надати список файлів коміту, хеш, фактичні результати перевірок і DOCX. Звіт лишається локальним за чинним правилом various files.

Попередню спробу commit було скасовано на прохання користувача. Після завершення виправлень звітів користувач повторно прямо підтвердив цей план; дозвіл на push, APK чи Render не надано.
