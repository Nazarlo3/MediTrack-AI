# Підготовка та публікація 0.4

- Користувач підтвердив реліз 0.4 та оновлення Render.
- Нове порівняно з 0.3: необов’язкові тривалість 1–30 днів та інтенсивність 0–10, валідація, передавання AI, підтримка повторів/уточнень та історії.
- Вихідний коміт: 38804bd. Звіти, матеріали ЛР2–3 та локальні налаштування залишаються поза релізним комітом.
- План — [plan.md](plan.md), опис — [v0.4.md](../../releases/v0.4.md).

## Збірка та перевірки

- Новий контракт на Render уже доступний: `/health` HTTP 200, OpenAPI містить duration_days/intensity. Один справжній синтетичний запит повернув HTTP 200 за 747 мс, details_used=true, у поясненні є «1 дн.» і «2/10». Окремий deploy не запускався, бо необхідна підтримка вже працює. Ключі та налаштування хмарного сервісу не змінювалися.
- Збірка в чистій копії коміту 38804bd з єдиною зміною конфігурації — 0.4/code 4. Невідібрані ЛР2/ЛР3 й локальні зміни не копіювалися. Використано існуючий release-ключ; секретні параметри не друкувалися та не додаються до Git.
- `:app:assembleRelease --offline`: BUILD SUCCESSFUL за 1 хв 34 с, усі 47 Gradle-задач виконано, включно з lintVitalRelease. Відомі попередження deprecated TabRow і native debug symbols залишилися; залежності не змінювалися.
- APK: 2 740 733 байти, versionName 0.4/versionCode 4, com.example.meditrackai, debuggable=false. Apksigner verify успішний; сертифікат SHA-256 збігається з локальним APK 0.3, який раніше звірено з публічним. Zipalign 16 KB перевірено.
- SHA-256 APK: e2309f6c50e4c5abfab12fb604eb16b14cc6dfb7b09c1be815368fd791a542a0. APK, SHA256SUMS і технічні протоколи — локально в `.artifacts/release-v0.4`; до Git додається лише опис.
- Код функції після підтверджених 38 backend / 61 Android unit-тестів не змінювався; набори не повторювали. Нову release-версію на телефон не встановлювали, користувацькі дані й debug залишені без змін.

## Публікація

- Коміт коду релізу 1c62836e94ded74595b4bcf43cc15f98d7da8bb2 запушено в main. Усі Android/Gradle-файли коміту зіставлено з реальною чистою копією, в якій зібрано APK; відмінностей немає. APK зібрано перед створенням цього коміту, що зафіксовано в локальних BUILD-INFO.
- [GitHub Release v0.4](https://github.com/Nazarlo3/MediTrack-AI/releases/tag/v0.4) опубліковано з тегом на цей коміт. Додано [MediTrackAI-0.4-release.apk](https://github.com/Nazarlo3/MediTrack-AI/releases/download/v0.4/MediTrackAI-0.4-release.apk) і [SHA256SUMS.txt](https://github.com/Nazarlo3/MediTrack-AI/releases/download/v0.4/SHA256SUMS.txt).
- До публікації перевірено розміри й GitHub digest обох assets; після неї APK завантажено за публічною адресою, SHA-256 збігся з локальним. Сирий результат публікації — `.artifacts/release-v0.4/publication.json`.
- Старі v0.2/v0.3 збережені. Телефон і його дані не змінювалися. Невідібрані робочі файли звірено за початковими SHA-256, вони незмінні. README і опис оновлено фактичними посиланнями; цей запис публікації є наступним документаційним комітом, а тег v0.4 залишається на перевіреному коді 1c62836.
