# Перевірки Google Sheets — 09.11.2026

- Backend: 59 тестів успішні, включно з 8 тестами Sheets (memory transport). Перевірено вибір сховища, literal values без виконання формул, round trip, owner-scoped delete, блокування пізніх записів, дублі, статистику, строк, змінену схему/fail closed, нову згоду 2. Повний набір містить попередні незакомічені тести користувача; це не кількість тестів окремого чистого коміту.
- Після фінального перегляду додано ще одну перевірку місткості: при 10 000 відкликаних ключів новий збір припиняється, але видалення існуючих записів продовжує працювати. Оновлений окремий набір Sheets — 9/9 успішний; повний 59-тестовий набір вище стосується попередньої контрольної точки.
- Android: unit-тести/assembleDebug/lint виконано після оновлення повідомлення та consent_version. Точні числа — [verification.json](verification.json). Живі перевірки телефона з feature_23 тут повторно не запускались; новий APK зібрано, але на телефон не встановлено.
- Реальний Google REST через той самий SheetsTransport у режимі curl: створено три керовані аркуші, два синтетичні записи; HTTP API TestClient із FakeProvider. Підтверджено читання, актуальну статистику, дедуплікацію, видалення тільки одного власника й відмову пізньому запису відкликаного ключа. У finally видалено обидва тестові тексти, загальна кількість повернулася до початкової. Тест повторено зі згодою 2 після оновлення контракту. Службові хеші відкликаних тестових ключів залишаються, текстів немає. Наявний «Аркуш1» збережено.
- Початкова ініціалізація повернула узагальнену транспортну помилку. Додано безпечну діагностику статусу й перевірено схему; наступні обидві повні перевірки успішні. Точну причину первинної помилки не встановлено; первинний лог залишено локально.
- Ключ і backend/.env виключені з Git. Виведення ключів/токенів відсутнє; перевірені вибрані файли на очевидні секрети, git diff --check успішний. Це не аудит усієї Git-історії. Нова залежність google-auth[requests] обґрунтована OAuth доступом до приватної таблиці; локально встановлено 2.62.1.

Межі: не було реального AI-запиту Groq, живого Android→оновлений backend→Google сценарію, візуального тесту UI або оновлення Render. Статистика у Sheets — серверний snapshot, не Excel-формули; синхронне оновлення snapshot/даних і видалення/відкликання атомарне в одному Google batchUpdate. Блокування лише для одного процесу; зовнішнє ручне редагування/кілька серверів не підтримуються. Google-історія версій може зберігати попередні дані, чого видалення рядків не гарантує стерти.

Локальний .env підготовлений для нової таблиці й приватного JSON; поточний старий сервер автоматично не перезапускався. Для застосування потрібен перезапуск backend, для хмари — окреме розгортання з secret file та одним worker. Старі підтверджені артефакти ЛР7/feature_23 не переписані.
