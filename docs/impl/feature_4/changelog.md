# Журнал змін: Приховане дебаг-меню перевірки сповіщень (feature_4)

## Дата
- 7 жовтня 2026 року

## Що змінено
- Створено приховане дебаг-меню діагностики системних сповіщень, яке відкривається після 5 швидких натискань на заголовок "MediTrack AI" в екрані `SymptomCheckScreen` (працює виключно у Debug-збірках при `FLAG_DEBUGGABLE`).
- Створено `DebugAlarmReceiver` для прийому сигналів `AlarmManager` та відображення сповіщень через `NotificationManager`.
- Додано перевірку статусу системного дозволу `POST_NOTIFICATIONS` та кнопку для його запиту.
- Додано перевірку наявності `NotificationChannel` ("med_test_channel") та кнопку для його створення.
- Додано кнопку "Тестове сповіщення зараз" для миттєвої відправки тестового сповіщення.
- Додано кнопку "Запланувати тест через 1 хвилину" з використанням `AlarmManager.setAndAllowWhileIdle` без додавання дозволу `SCHEDULE_EXACT_ALARM`.
- Додано список збережених ліків із діагностичною позначкою ("Ні — системний планувальник у застосунку відсутній").
- Додано діагностичний лог подій у пам'яті (останні 20 дій з точним часом).

## Перевірка
- Запуск `:app:assembleDebug` та `:app:assembleRelease` — обидві збірки проходять повністю успішно.
- Ручна перевірка відкриття дебаг-меню через 5 натискань на заголовок у Debug-збірці.
- Перевірка недоступності дебаг-меню у Release-збірці.

## Обмеження
- Автоматичне нагадування про прийом ліків за графіком у застосунку відсутнє (дебаг-меню перевіряє лише базову доставку системних сповіщень).
- Діагностичний лог подій зберігається виключно в оперативній пам'яті та зникає після виходу з дебаг-меню або перезапуску додатка.
- Для тесту через 1 хвилину використано `setAndAllowWhileIdle` (може мати невелику затримку спрацьовування в режимі енергозбереження/Doze Mode).
