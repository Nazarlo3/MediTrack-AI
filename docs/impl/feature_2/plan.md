# План реалізації Feature 2: Профіль ліків та список прийому (Medication Tracker & Checkmarks)

## 🎯 Мета функції
Додати класичну не-AI функціональність медичного трекера для щоденного керування прийомом лікарських засобів:
1. **Списки препаратів:** Додавання назви, дозування та реальної фотографії з галереї смартфона.
2. **Гнучкий розклад прийому:** Вибір точної години (наприклад `08:00`), зв'язку з їжею ("перед обідом"), днів тижня (вівторок, середа) та перевірка дати завершення курсу (за замовчуванням +7 днів від сьогодні, заборонено минулі дати).
3. **Нагадування:** Системний запит дозволу на сповіщення (`POST_NOTIFICATIONS`) при додаванні ліків.
4. **Чекмарки та локальне збереження:** Прапорці «Прийнято» / «Не прийнято» та персистентне збереження списку на пристрої (`SharedPreferences` / Gson).

---

## 📐 Покроковий технічний план (Feature Roadmap)

### Крок 1: Оновлення структури даних (Models & Permissions)
- Додати дозволи на сповіщення у `AndroidManifest.xml` (`POST_NOTIFICATIONS`).
- Розширити data-клас `MedicationItem`: `id`, `name`, `dosage`, `photoUri`, `daysOfWeek`, `mealSlot`, `endDate`, `isTaken`.

### Крок 2: Розширення ViewModel та Логіки збереження
- Додати управління станом списку ліків у `SymptomViewModel`: `addMedication()`, `toggleMedicationStatus()`, `deleteMedication()`.
- Персистентне збереження через `SharedPreferences` + Gson (`medications_list_v1`).

### Крок 3: Розширення UI (Jetpack Compose)
- Інтегрувати системний лаунчер вибору фото з галереї (`GetContent()`) та відображення мініатюри через `contentResolver`.
- Додати валідацію дати (заборона вибору дати в минулому) та розрахунок дати курсу за замовчуванням (+7 днів).
- Додати вибір точної години прийому та запит дозволу на сповіщення.

### Крок 4: Інтеграція та тестування
- Перевірити вибір реального фото з галереї.
- Перевірити валідацію дати та збереження після перезапуску.
