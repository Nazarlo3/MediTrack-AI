- Додано optional duration_days (strict int 1–30) та intensity (strict int 0–10), незалежну domain-перевірку й server-owned details_used. Нові поля необов'язкові: старі description/context і відповіді для початкового аналізу залишаються сумісними. Змінено domain/models/service/AI, endpoints не змінено.
- `build_user_message` готує додаткові дані окремим блоком; промпт просять врахувати їх у поясненні, не вигадувати пропущені, не задавати urgency лише за числами. Без атрибутів description у повідомленні не змінений. Нових клінічних порогів/залежностей немає.
- Android: поля rememberSaveable з межами; domain/DTO mapping; збереження початкових атрибутів при retry/clarify; текстові метадані історії/контексту без міграції старого JSON. Старий backend без details_used дає зрозумілу помилку й не створює фальшиво успішну історію.
- Новий suite details у runner: baseline — вже 0.3/16 категорій, current — нова функція. Параметри однакові (400 tokens, temperature 0.1, timeout 15 с); початковий HEAD не видається за кінцевий коміт, хеші джерел/промптів записані.
