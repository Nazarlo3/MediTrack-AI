# Редизайн

## Реалізовано

- Компактна шапка замість великого бренд-банера; нижня навігація «Мої ліки / Аналіз AI / Історія», початковий розділ — ліки. Збережено доступ до налаштувань і debug-жест.
- Підсумок сьогоднішніх доз, прогрес і наступний час за графіком; оновлення часу лише у foreground. Форма додавання відкривається окремо й закривається після успішного збереження/Back; список більше не прихований за довгою формою.
- Прийняті дози лишаються зеленими, звичайні картки стали нейтральними з тонкою рамкою. Коротка дія «Прийняти» читається з великим шрифтом. Дозволи й оновлення нагадувань доступні через «Нагадування та дозволи».
- Компактний AI-ввід, розгортані необов'язкові поля без зміни валідації; історія — окремий розділ. Перемикання не стирає поточну чернетку. Вирівняно додаткові поля після перегляду фактичного знімка.
- Налаштування — простий список: тема, чинний перемикач/подробиці збору, «Про застосунок» із версією/GitHub, «Діагностика» з технічними даними/health/копіюванням. Збережено Back і вибір теми.

- RedesignUiTest і SettingsDiagnosticsTest — **2/2 успішні окремими instrumentation-запусками**, 0 skips, без live API. Перевірено навігацію, початковий список, відкриття/закриття додавання, виділення прийнятого, чернетку після перемикання, розгортання параметрів, About/GitHub/Diagnostics, перемикач і копіювання діагностики.
- Знято й переглянуто 7 синтетичних screenshots: ліки/AI/параметри/історія/налаштування/About/ліки з fontScale 1.5. Перевірені світла й темна теми; системні відступи тестової оболонки узгоджено з MainActivity. Знімки локально в .artifacts/feature28/screens, без реальних медичних даних.
- Перші невдалі спроби збережені локально: старий SettingsDiagnosticsTest переходив до About перед пошуком подробиць збору — маршрут виправлено; наступний спільний запуск утратив Compose hierarchy другого тесту. Обидва тести після цього виконані окремо та успішні. Це не твердження про стабільний повний UI-suite.

## Межі

Без commit/push, нового публічного APK, зміни версії, API/JSON/серверного коду чи нових бібліотек. Реальні AI-відповіді/нагадування наступного дня цим UI-прогоном не перевірялися. Screenshot-перегляд не замінює повний TalkBack/контраст-аудит; прогрес показує статуси доз, а не доводить доставку сповіщення. Специфікація — docs/ui-design.md.
