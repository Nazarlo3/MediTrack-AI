# Редизайн MediTrack

Напрям: спокійна палітра Material3, компактна верхня панель, нижня навігація «Мої ліки / Аналіз AI / Історія»; список прийомів замість постійно відкритої форми. Ліки — початковий розділ, додавання — окремий стан із Back/чернеткою. AI — ввід + розгортані необов'язкові параметри, історія окремо. Налаштування — компактний список, «Про застосунок» і «Діагностика» як підрозділи.

Файли: ui/{SymptomCheckScreen,SymptomComponents,MedicationSection,AppSettingsScreen}.kt; ui/components/{MediTrackShell,AppComponents}.kt; ui/theme/{Color,Type}.kt за потреби; res/values/strings.xml; відповідні UI-тести; цей plan/changelog/verification, короткий UI-опис у docs. Не змінювати API, моделі, дані, версію чи сервер. Без нових бібліотек, commit/push/deploy.

Перевірка: build/test APK/lint; одна цільова UI-перевірка навігації/форм/чернеток із синтетичними даними, світла/темна тема та великий шрифт у screenshot-тесті; за доступного телефона install -r без очищення даних, перегляд фактичних знімків. Якщо телефона немає — повідомити, не називати UI візуально перевіреним.

Рекомендації: https://developer.android.com/design/ui/mobile, https://m3.material.io/foundations/, https://developer.android.com/design/ui/mobile/guides/patterns/settings. Це власний дизайн MediTrack на основі рекомендацій, а не копія/схвалення Google.
