# 17.10.2026 — Збереження теми

Кнопку налаштувань оформлено як шестерню на тонованому фоні з описом для доступності.

Додано «Налаштування» з трьома варіантами: системна, світла, темна. ThemeSettings записує вибір у приватні SharedPreferences до публікації StateFlow; помилка збереження показується через Snackbar. Бейджі urgency використовують вибрану тему.

Ізольований Android-тест перевірив усі три варіанти після створення нового ThemeSettings. APK зібрано й встановлено без видалення даних. Адресу сервера, API-ключ, експорт та імпорт не додавали. Залежності без змін. Комітів і push немає.
