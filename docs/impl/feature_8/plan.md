# План feature_8 — контекст AI та категорії

16.10.2026 користувач попросив виправити оцінку «розбив монітор ногою» й додати категорії.

1. Проаналізувати системний промпт і обробку відповіді в backend/ai_service.py; зберегти API-ключ поза Git.
2. Розширити категорії з 7 до 16 без видалення старих. Враховувати можливе ушкодження, заперечення, метафори та невизначеність, не вигадуючи діагнозів.
3. Узгодити SymptomResponseValidator в Android і додати перевірку однаковості наборів.
4. Перевіряти JSON і обов’язкові поля; не знижувати невідому терміновість до «звичайне».
5. Додати backend unit-тести та Android регресійний тест. Перевірити приклади на Groq синтетичними запитами, фіксуючи ліміти окремо від семантичної невідповідності.
6. Оновити KB, API-контракт, README, testing і changelog; зібрати debug APK. Комітів, push і deploy не робити без наступної вказівки.

Файли: backend/ai_service.py, backend/tests/test_ai_service.py, Android SymptomResponseValidator.kt і його unit-тест, README та релевантні docs. Нових залежностей, моделі API, діалогового режиму чи правил на ключових словах у Kotlin не додаємо.
