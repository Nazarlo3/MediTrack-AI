# Журнал змін

- 05.11.2026: план підтверджено; перевірено точки інтеграції, наявні зміни збережено. Реалізація триває; перевірки ще не виконано.
- Додано SQLite repository/service/API: тільки поточний запит і типізована відповідь, час/модель/атрибути; без raw context. Старі клієнти не включають збір, сервер вимкнений без COLLECTION_DB_PATH. Адміністративний доступ окремим секретом, capability-scoped DELETE, дедуплікація UUID, атомарне відкликання ключа проти пізніх записів.
