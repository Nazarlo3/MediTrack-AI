## Межі та завершення

Локальний шлях перевірено. Render і публічний APK не оновлювали. Немає перевірки завершення процесу/перезавантаження/наступного дня/зміни поясу нагадувань чи release-інсталяції; не плутати це з наявністю коду підтримки. Невеликий синтетичний набір не доводить клінічної якості або гарантованої доступності.

Дозвіл після F07 повернуто. Для завершення передачі: фінальний commit або lab7-final з перевіреним переліком файлів. README містить запуск, конфігурацію, команди й сценарій відновлення. План захисту — [defense.md](defense.md). Звіти й фото локальні, різні старі зміни не включати до коміту ЛР7.
