# Журнал змін

Доповнення: feature_25 включається до 0.5.1; RAM-реалізацію нижче замінено SQLite outbox/підтвердженим sync fallback. Це журнал попереднього checkpoint; актуальна підготовка версії й коміту — [0.5.1](../release_0_5_1/changelog.md).

## Реалізовано
- Єдиний DI-граф Application; актуальний persisted enabled та синхронізація налаштувань між екземплярами.
- API: 30 AI/10 DELETE запитів за хвилину на клієнта, 120 загалом, 4 одночасно; 64 КіБ/10 с для тіла; 429/Retry-After, 413, 408. Release HTTP заборонений, debug HTTP збережений.
- DELETE невідомого ключа не наповнює реєстр відкликань. Враховані запити під час AI та в черзі; пізнє збереження після видалення блокується.
- Google-запис не блокує AI: bounded RAM-черга на 64 задачі, до 3 спроб, дедуплікація. Статус queued чесно відрізняється від saved.
- Нагадування підтверджується після notify; до 3 повторів після збою в межах дня. Збережені стабільні notification tags, дії й графіки. Clock/poster ін'єктуються для перевірки реального scheduler без зміни системного часу.
- Окремий екран налаштувань: тема/збір/подробиці, GitHub, фактична версія/код/тип збірки, пристрій/Android/встановлення/оновлення/мова/пояс, дозволи/найближчий alarm/локальні лічильники/обсяг фото. Перевірка health без AI; останній HTTP-код/час/request ID та копіювання технічної діагностики без медичних текстів і секретів.

## Межі
- RAM-черга може втратитися при рестарті; queued не підтверджує Google-запис. Один процес/інстанс. Стійка черга/спільні ліміти потребують окремого сховища.
- API без акаунтів/атестації; процесні ліміти не гарантують захист від розподіленого зловживання. Потрібна довіра лише до реального reverse proxy у конфігурації uvicorn.
- notify не гарантує, що користувач побачив повідомлення; повне вимкнення телефона/force-stop/системні обмеження залишаються обмеженнями Android. Нова перевірка відтворює помилку публікації; не підміняє тест наступного дня/reboot.
- Комітів, push, релізу та розгортання немає. Debug на телефоні оновлено; production працює на попередньому backend.
