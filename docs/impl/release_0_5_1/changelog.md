## Розгортання й межі

Read-only перевірка Render: free, постійного диска немає. SQLite стійкий лише за збереженого диска; тариф/зовнішня БД — окреме рішення. У режимі без диска синхронний Google може затримувати відповідь; непідтверджене збереження не видається за успіх. Ліміти API не замінюють акаунти/атестацію; один worker/інстанс обов'язковий.

Цей етап завершується локальним комітом. Push, розгортання Render, публікація APK та створення платних ресурсів не виконуються. Поточний публічний реліз — 0.5.
