# Changelog feature_7 — ЛР4

## 16.10.2026 — Реалізація базового рівня

- SymptomHistoryItem: UUID, createdAt, status=готово; старий timestamp збережено.
- HistoryJsonCodec: явна міграція старих JSON, перевірка полів та унікальності ID, порядок за датою й ліміт 20. Старі дати не вигадуються.
- LocalDataStore: ключ symptom_history_v2, збереження ID після міграції, читання за ID, серіалізація операцій між екземплярами, очищення старих копій. Пошкоджений v2 не замінюється старим.
- SymptomResponseValidator: відома категорія/терміновість, непорожні пояснення й застереження. HTTP-помилки, порожнє тіло й неповний результат не записуються як готові.
- SymptomViewModel: завантаження/недоступність історії, вибір запису за ID, захист від одночасного подвійного запуску запиту.
- HistorySection: порожній стан, короткий список, історичні деталі з повним прокручуваним текстом, кольори терміновості, дата/статус, підтвердження очищення. Початкова вкладка «Мої ліки» збережена.
- Додано 14 unit-тестів і 10 інструментальних тестів сховища/UI без нових залежностей. Android-тести використовують ізольовані імена SharedPreferences.
- Оновлено README, architecture, requirements, known-limitations, decisions і testing.

## Перевірки

- Unit + lint + debug APK + Android test APK: BUILD SUCCESSFUL (59s, фінальна компіляція додаткових тестів 4s).
- 30 unit-тестів, 0 помилок/пропусків; lint: 0 помилок, 40 попереджень.
- Інструментальні тести лише скомпільовано; пристрій/емулятор не підключений.
- Ручна демонстрація, перезапуск процесу й регресія нагадувань очікують перевірки користувачем.
- Зміни фіксуються локальним комітом за вказівкою користувача; push, нового релізу й змін підпису не виконано.

## 17.10.2026 — Видалення однієї перевірки

- Додано видалення з картки та деталей із підтвердженням; скасування не змінює даних.
- LocalDataStore фільтрує за ID; однакові описи/час не спричиняють видалення іншого запису. Старі резервні ключі прибираються й при частковому видаленні.
- Після успішного запису оновлюється список, деталі видаленого запису закриваються; помилка збереження показується окремо.
- 31 unit-тест успішний, lint 0 помилок / 40 попереджень, debug APK та Android test APK зібрано.
- На Android 15 виконано 14 інструментальних тестів історії: OK (14 tests). Стандартний Gradle runner не зміг надати дозволи; успішно виконано прямий запуск adb am instrument без прапорця автоматичного надання дозволів.
- Підпис APK збігається з установленим, оновлено через install -r без видалення даних. Новий скриншот списку переглянуто. Комітів і push доповнення немає.
