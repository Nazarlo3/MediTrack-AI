## 17.10.2026

- Телефон підключено через Wi-Fi ADB; Android 15. Погоджено перевірку, кілька скриншотів і підготовку матеріалу для звіту.
- План: [plan.md](plan.md). Фактичні результати додаються після виконання.

### Реалізація й результати

- Додано лише Lab5PhoneScenarioTest у androidTest: синтетичні приклади, ізольовані SharedPreferences, справжній Screen/ViewModel/use case/repository/Retrofit → локальний FastAPI → справжній Groq. Для негативного сценарію IOException і затримка ін’єктовані на API-межі; Wi-Fi не вимикався.
- Перед adb install -r збережено локальну приватну резервну копію. Встановлено поточний debug і test APK без видалення даних. Xiaomi 23030RAC7Y, Android 15/API 35, Wi-Fi ADB.
- Перша збірка test APK успішна (7 с). Початковий прогін 3 тестів (15.746 с): error/retry і cancel пройшли, live-тест зупинився на неоднозначному селекторі однакового пояснення в результаті та історії. Це помилка тесту, не runtime.
- Уточнено селектор, test APK перезібрано (4 с), повторено лише liveAnalysisClarificationAndPersistentHistory: OK (1 test), 9.299 с. Отже, успішні три різні сценарії; спільного фінального OK (3 tests) не було.
- Аналіз/уточнення підтверджено справжнім Groq, context_used і X-Request-ID; історія перечитана новим LocalDataStore, деталі відкриті за ID. Реальний повтор зберіг опис. Cancel зберіг початковий ввід/чернетку та не додав записів.
- Експортовано й переглянуто три PNG у локальному docs/various files/screenshot/ЛР5; success/error достатньо для звіту, третій — додатковий доказ cancel.
- Звичайний MainActivity після тестів запущено; початкова вкладка «Мої ліки» підтверджена UI-деревом. 96 початкових файлів SharedPreferences мають незмінні SHA-256, тестових prefs не залишилося.
- Створено локальний ЛР5_матеріали_для_звіту.md у папці Звіти; оновлено README/testing/architecture/ROADMAP/known-limitations. Production Kotlin/backend/Gradle не змінювалися, unit/backend набори повторно не запускали.
- Render/deploy, поворот, завершення процесу та реальне відключення мережі не перевірялися. Мережеву адресу в production не змінено. Commit/push не виконано.
- Завершення: локальний uvicorn зупинено (порт 18765 не слухається); тестового ADB reverse немає, інші перенаправлення не змінювалися. Посилання матеріалу/плану/журналу існують, git diff --check пройшов. Матеріал для звіту й PNG лишаються ігнорованими локальними файлами.
