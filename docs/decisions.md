# Architectural Decisions — MediTrack AI

## Прийняті рішення та причини

### 1. Використання FastAPI (Python) замість прямого виклику Groq з Android
- **Причина:** Безпека. Сховати API-ключ `GROQ_API_KEY` на сервері в змінних середовища `.env`, унеможливлюючи його витік чи декомпіляцію через мобільний APK.

### 2. Хостинг Render.com для бекенду
- **Причина:** Повна доступність сервера 24/7 з будь-якого мобільного інтернету без прив'язки до локальної Wi-Fi IP-адреси ноутбука розробника.

### 3. Модель Groq `qwen/qwen3.8-27b`
- **Причина:** Найбільш актуальна, стабільна та безкоштовна модель на Groq API із підтримкою гарантованого формату `json_object`.

### 4. Збільшення таймаутів OkHttp до 60 секунд
- **Причина:** Забезпечення надійного очікування прокидання хмарного сервера Render під час першого запиту без видачі помилки таймауту.
