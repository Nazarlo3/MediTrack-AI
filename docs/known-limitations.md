# Known Limitations — MediTrack AI

## Відомі обмеження
1. **Cold Start (Render Free Tier):** Хмарний безкоштовний сервер Render переходить у режим сну після 15 хвилин неактивності. Перший запит після перерви може тривати 15-25 секунд.
2. **Відсутність історії:** Додаток не зберігає історію попередніх перевірок на пристрої (поза межами MVP).
3. **Фіксовані категорії:** ШІ обмежений списком із 7 категорій для стабільності демонстрації.
4. **Ліміт запитів API:** Безкоштовний тариф Groq має добовий ліміт запитів, що достатньо для розробки та тестування, але не для високого продакшн-навантаження.
