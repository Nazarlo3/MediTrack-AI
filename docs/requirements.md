# Вимоги MediTrack AI

Актуальний код 04.11.2026: 0.4 та навчальна інтеграція ЛР7. Наявність функції в коді не означає її публікацію або перевірку всіх Android-сценаріїв.

## Реалізовано

1. Compose UI: початкова вкладка «Мої ліки», «Аналіз AI», тема, форми; опис 3–500 після trim, duration 1–30/intensity 0–10 необов’язкові. Idle/Loading/Success/NoResult/Error; retry, cancel і до трьох уточнень.
2. FastAPI: GET /health, POST /analyze-symptom, Pydantic/context/details; контрольовані 400/422/503/500, X-Request-ID без витоку stack trace/ключа.
3. Groq: 16 категорій, 3 urgency, explanation/disclaimer, follow_up_question, context_used/details_used, has_usable_result. Брак даних дає питання й окремий стан; технічний збій — помилку, автоматичного fake fallback немає.
4. Історія: до 20 придатних результатів, ID/дата/час, деталі, міграція, видалення одного/всіх із підтвердженням. NoResult/мережеві помилки не створюють завершених записів.
5. Ліки: фото/редагування, кілька часів до 12, статус кожного часу за датою; alarm, дні/кінець курсу, «Прийняв»/«Через 10 хв», дозволи/відновлення. Код відновлення не гарантує доставку після force stop.
6. Архітектура: domain/use case/repository/manual DI в аналізі Android; AnalysisService/AIProvider/Depends на backend. Ліки використовують попередню структуру ViewModel/LocalDataStore.
7. ЛР7: локальний debug URL через Gradle property, навчальний APK, 10 AI-прикладів, протокол функціональних перевірок, схема/KB/демонстраційний сценарій.

## Критерії ЛР7 та фактичний стан

[П’ять критеріїв приймання](impl/feature_22/plan.md), [перевірки та відкриті пункти](impl/feature_22/verification.md). Debug встановлено; 64 Android unit-тести та 42 backend-тести проходять, lint без помилок. Підтверджено всі 10 функціональних сценаріїв, включно з F07 від 05.11.2026 після ручної відмови у сповіщеннях. Остаточний Git commit/тег має відповідати APK. Успішний шлях — реальний AI; fake/mock лише для явно позначених збоїв. Хмара/Google Play для ЛР7 не обов’язкові.

## За межами поточної реалізації

Офлайн-черга, синхронізація/акаунти, експорт/імпорт, редагування адреси чи API-ключа в UI, відновлення AI-діалогу після завершення процесу, клінічна валідація. Це не автоматично погоджений обсяг. [Обмеження](known-limitations.md), [пріоритети](ROADMAP.md).
