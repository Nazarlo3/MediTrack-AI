# MediTrack: UI 2026

Ціль — швидко побачити прийоми й виконати основну дію. Власний дизайн на основі [Android Design](https://developer.android.com/design/ui/mobile), [Material 3](https://m3.material.io/foundations/) та [settings patterns](https://developer.android.com/design/ui/mobile/guides/patterns/settings).

- **Оболонка:** компактний бренд/назва екрана й доступ до налаштувань угорі; три постійні нижні розділи: Мої ліки, Аналіз AI, Історія. Початково відкриваються ліки. Back із другорядних вкладок повертає до ліків; налаштування/форма обробляють свій Back.
- **Мої ліки:** підсумок дня, прогрес прийомів і наступний час за графіком. Це розрахунок MedicationSchedule, а не підтвердження доставки AlarmManager. Додавання — окрема форма, а не довга форма перед списком. Нагадування/дозволи доступні через окрему дію. Прийняті дози залишаються зеленими; неприйняті картки — спокійна поверхня з тонкою рамкою. Дія «Прийняти» коротка й читабельна.
- **AI:** опис і одна основна дія. Тривалість/інтенсивність розгортаються за бажанням; їхня валідація й значення збережені. Історію прибрано з цієї вкладки; перехід між розділами зберігає поточну чернетку через saveable state, без нової персистенції медичних текстів.
- **Налаштування:** компактний вибір теми, чинний перемикач і подробиці збору даних, окремі «Про застосунок» з версією/GitHub та «Діагностика» з перевіркою backend/копіюванням. Детальний текст не перевантажує головний список налаштувань.
- **Стиль:** існуюча teal-палітра й типографіка Material3, спільні 16–20 dp поля, виразна головна дія, менше декоративних контейнерів. Терміновість/помилки й статус прийому не залежать лише від кольору — збережені текстові позначення.

Код: ui/components/MediTrackShell.kt, MedicationTodaySummary.kt, MedicationSection.kt, SymptomCheckScreen.kt, SymptomComponents.kt, AppSettingsScreen.kt, MedicationCard.kt.
